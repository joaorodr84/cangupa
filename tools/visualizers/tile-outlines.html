Cangupa Tile Outlines

Cangupa tile outlines

Every combination of the game's 5 tile kinds, both themes, and 2 outline treatments. Both now use the same theme-aware ink colour (near-black on the light board, near-white on the dark one) — no single fixed colour reads against every tile's own face and lip, so colour can't be what tells a legal move from a hint. Width and style do that instead: legal move is a solid 2px border, hint a dashed 4px one — distinct from each other on sight, and still backed by the live app's own pulse animation on the hinted tile, which this static page can't show. 20 swatches total. Tile face, edge and mark colours don't change between themes; only the board underneath does, so each row holds the outline fixed and varies the board it has to read against.
